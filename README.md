# Прилагательное перед существительным в турецком

Гайд в сторителлинг-стиле: шесть правил, шесть историй, шесть тренажёров с озвучкой (güzel ev / ev güzel, неизменяемое прилагательное, `büyük bir`, субстантивация, `kıpkırmızı`, `-lı / -sız`), шпаргалка и тест. В конце — витрина платформы **Alterna Timur A0 → C1** с реальными скриншотами и демо-видео.

Mobile-first, без зависимостей: один `index.html` + `media/`.
